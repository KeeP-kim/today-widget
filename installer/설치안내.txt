오늘은 위젯 - 설치 안내
======================================================================

[ 빠른 설치 ]

  1. zip 을 **두고 쓸 폴더에 푼다** (문서, D:\Tools, 어디든 쓰기가 되는 곳)
  2. 그 폴더의 install.cmd 더블클릭
  3. 둘 곳을 묻는다. 그대로 쓰려면 그냥 Enter
  4. 끝. 바탕화면에 "오늘은" 아이콘이 생기고 위젯이 뜬다


[ 어디에 깔리나 ]

  **푼 자리에 그대로 둔다.** 다른 데로 복사하지 않는다.
  그래서 나중에 폴더째 옮기거나 지우는 것이 그냥 된다.

  다른 곳에 두고 싶으면 3번에서 경로를 적으면 된다. 없는 폴더면 만든다.
  쓸 수 없는 곳(Program Files 등)을 적으면 깔지 않고 멈춘다.

  ※ 내려받기·바탕화면·문서처럼 **여러 가지가 섞여 있는 폴더**에 풀었거나
    그런 곳을 적으면, 거기에 그대로 두지 않고 그 아래 '오늘은' 폴더를 만들어
    넣는다. 남의 파일과 섞이면 나중에 무엇을 지워야 할지 알 수 없기 때문이다.
    드라이브 루트(D:\ 같은 것)도 마찬가지다.

  ※ 압축을 풀지 않고 zip 을 연 채로 install.cmd 를 누르면, 그 자리는
    Windows 의 임시 폴더다. 거기 두면 언젠가 지워지므로 설치가 멈춘다.
    먼저 풀어 주세요.


[ 무엇을 건드리나 ]

  이 설치가 손대는 것은 아래가 전부다.

    - 둔 폴더에 놓는 파일 : Onuln.exe / Onuln.dll / launch.vbs / launch.ps1 /
                            config.json / assets\widget.ico
    - 그 파일들의 '차단 해제' (인터넷에서 받은 표시를 푸는 것)
      **우리가 놓은 이 파일들에만** 한다. 같은 폴더의 다른 파일은 건드리지 않는다.
    - 바탕화면에 '오늘은' 바로가기 하나
    - 이미 떠 있던 오늘은 위젯을 내린다 (파일을 덮어쓰려면 내려야 한다)

  레지스트리는 위젯에서 "Windows 시작 시 자동 실행" 을 켤 때만 건드리고,
  그것도 현재 사용자 영역(HKCU)이다.

  관리자 권한 필요 없음. 레지스트리는 "Windows 시작 시 자동 실행" 을
  켤 때만 건드리고, 그것도 현재 사용자 영역(HKCU)이다.


[ 필요한 것 ]

  Windows 10 (1903 이상) 또는 Windows 11
  .NET Framework 4.8   -> 위 두 버전에는 원래 들어 있다. 따로 설치할 일은 거의 없다.

  설치 프로그램이 알아서 확인하고, 없으면 알려준다.

[ 안 될 때 ]
======================================================================

■ install.cmd 를 눌렀는데 창만 뜨고 아무 일도 안 난다
   -> PowerShell 스크립트를 정책으로 막아둔 PC 다.
      (그룹 정책으로 막아 두면 -ExecutionPolicy Bypass 도 안 통한다.
       관리되는 PC 에서 흔한 구성이라 이쪽일 확률이 높다)
      이 폴더의  Onuln.exe  를 그냥 더블클릭하면 그대로 돈다.
      (설치 프로그램 없이도 폴더 통째로 두고 쓰면 된다.
       단, 쓰기가 되는 폴더여야 한다. Program Files 밑은 피할 것.
       바탕화면이나 문서 폴더가 무난하다.)

      이 방식으로 쓸 거면 launch.vbs 와 launch.ps1 을 지워라.
      그래야 "Windows 시작 시 자동 실행" 이 exe 를 등록한다.
      (파일이 남아 있으면 런처를 등록하는데, PowerShell 이 막힌 PC 에서는
       로그온할 때마다 조용히 실패한다)


■ "Windows의 PC 보호" / SmartScreen 파란 창이 뜬다
   -> 서명이 없는 프로그램이라 그렇다. 정상이다.
      "추가 정보" -> "실행" 을 누르면 된다.

      install.cmd 로 설치하면 차단 해제(Unblock)를 자동으로 해주기 때문에
      대부분 이 창이 안 뜬다.


■ Onuln.exe 가 아예 실행이 안 된다 (스마트 앱 컨트롤 등)
   -> launch.vbs 를 더블클릭해 봐라.
      exe 가 막히면 자동으로 DLL 을 메모리로 올려 실행한다.
      대신 메모리를 좀 더 쓴다 (8MB -> 90MB).


■ 숫자가 전부 --- 이고 상태등이 빨간색이다
   -> 방화벽 / 프록시 문제일 가능성이 크다. 순서대로 확인:

      1) 사내 프록시에 로그인 계정이 필요한 경우
         v0.49 부터는 Windows 로그온 계정으로 자동 인증한다.
         브라우저에서 인터넷이 되면 위젯도 된다.

      2) 그래도 안 되면 도메인이 막힌 것이다.
         브라우저에서 아래 주소가 열리는지 확인해 봐라.

            https://m.stock.naver.com      (환율 / 주식)
            https://api.upbit.com          (코인)
            https://api.open-meteo.com     (날씨)
            https://ecos.bok.or.kr         (금리)
            https://api.github.com         (새 버전 확인 - 없어도 나머지는 다 된다)

         열리지 않는 항목은 그 종목만 위젯에서 지우면 된다
         (꾹 눌러서 편집 모드 -> 빨간 - 버튼).

      3) SSL 검사를 하는 망이라도 보통 그냥 된다.
         그 인증서가 Windows 인증서 저장소에 이미 들어 있기 때문이다.


■ 금리 항목만 --- 로 나온다
   -> 한국은행 ECOS 인증키 문제다. config.json 의 "ecosKey" 를 확인.
      키는 ecos.bok.or.kr -> 오픈API 에서 무료로 다시 받을 수 있다.


■ 새 버전이 나오면 어떻게 아나
   -> 새 버전이 있을 때만 한 줄이 뜬다. 카드로 쓰면 맨 아래에,
      가장자리에 붙여 놨으면 그 바 안에 뜬다. 누르면 받는 곳이 열린다.
      하루 한 번 api.github.com 에서 이 앱의 릴리스를 본다
      (GET 하나뿐이고 본문도 쿠키도 없다. 앱 버전이나 설치 식별자도 안 붙는다).
      지금 버전과 지난 변경 내역은 우클릭 -> 정보 -> 로그 에서 볼 수 있다.
      알림이 싫으면 우클릭 -> "새 버전 알림" 을 끈다. 끄면 그 조회도 안 한다.

      받는 곳 : https://github.com/KeeP-kim/today-widget/releases


■ 위젯이 화면 어딘가로 사라졌다
   -> config.json 을 메모장으로 열어  "x": null,  "y": null  로 바꾸고
      다시 실행하면 기본 위치로 돌아온다.

[ 알아둘 것 ]
======================================================================

  - 이 꾸러미의 config.json 에는 개인 정보가 하나도 없다.
    인증키도, 집 좌표도, 개인 종목 목록도 안 들어 있다 (예시 설정 그대로다).
    쓰는 사람의 위치를 미리 넣어 두지 않는 쪽이 기본값이라고 보고 그렇게 두었다.

  - 날씨 지역은 처음 실행할 때 접속 IP 로 대충 잡는다.
    정확히 넣으려면 날씨 영역을 꾹 눌러 편집 모드 -> + -> 지역명 검색.
    필요 없는 지역은 빨간 - 로 지운다.

  - 금리/물가 항목을 쓰려면 한국은행 ECOS 인증키가 필요하다.
    ecos.bok.or.kr -> 오픈API 에서 무료로 받아 config.json 의
    "ecosKey" 에 넣는다. 안 넣어도 나머지는 전부 돈다.

  - "항상 위" 가 켜져 있다. 다른 창을 가리는 게 싫으면
    위젯 우클릭 -> "항상 위에" 를 끈다.

  - 나가는 통신만 한다. 서버를 열거나 대기하지 않고,
    받은 데이터를 어디로도 보내지 않는다. 수집도 텔레메트리도 없다.
    저장하는 파일은 설치 폴더의 config.json 하나뿐이다.
    (즐겨찾기를 쓰면 바로가기 사본이 설치 폴더 아래 앱저장\ 에 들어간다)

[ 제거 ]
======================================================================

  1. 위젯 우클릭 -> 종료
  2. 위젯 우클릭 -> "Windows 시작 시 자동 실행" 이 켜져 있었다면 먼저 끈다
     (이미 지웠다면 regedit 에서
      HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
      의 "오늘은" 값을 지운다)
  3. 깔아 둔 폴더 삭제 (설치할 때 화면에 '둔 곳' 으로 찍힌 자리다.
     기본대로 두었다면 zip 을 푼 그 폴더다)
  4. 바탕화면 바로가기 삭제

  그 외에 남는 것은 없다.
